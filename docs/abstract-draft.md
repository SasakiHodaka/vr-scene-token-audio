# 概要の下書き（実機評価前）

仮題：VR協調作業における操作関係と音響文脈を関連付けたScene Token構成の検討

VR協調作業の状況を遠隔で再現するには、位置や距離に加え、誰がどの対象を操作し、その操作がどの作業状態に対応するかを保持する必要がある。本研究では、操作イベントと音響文脈を関連付けるScene Tokenの構成を検討する。ドローン組立環境を対象とし、把持・解放・取付・工程状態の通知を、対象物IDおよびローカル単調時刻とともに記録する基盤を実装した。また、同じイベントに対応する距離・方向などの音響文脈を記録し、取得観測、CSV、関係表現の整合性を検査する処理を用意した。通知に含まれない操作者や未取得情報は不明値として残し、初期状態の記録と操作イベントを区別する。今後、実操作の記録を独立した根拠と照合し、同一の観測情報を用いた構造化ログと関係表現について、情報の保持、復元の正確性、データ量および処理負荷を比較する。
