# 研究の現状（2026-11-26）

研究題目は「VR遠隔協調作業(意味的空間音声・通信手法)のためのScene Tokenの構成」です。判断目的・受信条件・根拠の要求に応じたScene Tokenの情報構成を調べています。遮蔽は現在の研究対象外です。

## ローカルの実装

観測データを状態・イベント・関係・メタ情報・外部参照に構成し、目的別に抽出する仕組みがあります。熟練者PCで工程や発話の根拠を確認し、対象を確定し、指導候補を編集・承認できます。Unity側に指導文・リング・矢印の提示と、提示後の操作を同じ支援IDで照合する実装があります。Windows日本語ASR連携と訂正、認証付き配信、習熟度推定と合成例による学習もローカルで試験しています。
